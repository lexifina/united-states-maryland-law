# §2-504
The State shall disclose, in accordance with the Maryland Rules regarding discovery, whether facial recognition technology has been used in an investigation relevant to a criminal court proceeding or juvenile court proceeding under Title 3, Subtitle 8A of the Courts Article, the name of each facial recognition system used, a description and the names of the databases searched, and all results generated from the use of the facial recognition technology that led to further investigative action for each facial recognition system and for each database searched.

# §7-217
(a) The official text of a document is:
(1) until incorporation in the Code of Maryland Regulations, the text of the document in the most recent form in the Register; or
(2) after incorporation in the Code of Maryland Regulations, the text of the document in the most recent form in the Code of Maryland Regulations.
(b) Notwithstanding any discrepancy between the official text and any other text of a document, the official text is the only valid and enforceable text.

# §9-1006
(a)
(1) The State Archivist may appoint an Assistant State Archivist.
(2) The Assistant State Archivist has the powers and duties of the State Archivist:
(i) to the extent delegated by the State Archivist;
(ii) if the office of the State Archivist is vacant; and
(iii) if for any other reason the State Archivist is unable to perform the duties of office.
(b) The State Archivist may employ other staff in accordance with the State budget.

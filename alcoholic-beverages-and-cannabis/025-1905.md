# §25-1905
A license holder may sell only alcoholic beverages purchased from the Alcohol Beverage Services for the county if the holder's license is:
(1) a Class A, Class B, Class H, Class C, or Class D beer license;
(2) a Class B, Class C, or Class D beer and wine license; or
(3) a Class A-TP, Class B, or Class C beer, wine, and liquor license.

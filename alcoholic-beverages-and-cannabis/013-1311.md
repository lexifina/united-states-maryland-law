# §13-1311
(a) The fee for a Class C per diem beer license or a Class C per diem beer and wine license is:
(1) $20 per day for a religious, fraternal, civic, war veterans', charitable, or hospital supporting organization; and
(2) $30 per day for any other license holder.
(b) The fee for a Class C per diem beer, wine, and liquor license is:
(1) $35 per day for a religious, fraternal, civic, war veterans', charitable, or hospital supporting organization; and
(2) $50 per day for any other license holder.

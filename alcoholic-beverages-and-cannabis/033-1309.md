# §33-1309
(a) There is a Class C per diem (nonprofit charitable organization) beer, wine, and liquor license.
(b) The Board may issue a Class C per diem (nonprofit charitable organization) beer, wine, and liquor license to a nonprofit organization.
(c)
(1) The license is a multiple 1-day alcoholic beverages license.
(2) On application, the applicant:
(i) shall specify the dates of the events for which the license will be used; but
(ii) may not specify more than 12 dates.

# §11-904
(a) There are:
(1) a Class D beer, wine, and liquor license for on- and off-premises consumption; and
(2) a limited Class D beer, wine, and liquor license for on-premises consumption only.
(b) When an application for a new Class D beer, wine, and liquor license is filed, the Board may limit the sale of beer, wine, and liquor to allow on-premises consumption only.
(c) The annual license fees are:
(1) $1,200 for a Class D license; and
(2) $1,080 for a limited Class D license.

# §14-1308
(a) The fee for a Class C per diem beer license or a Class C per diem beer and wine license is $5 per day.
(b) The fee for a Class C per diem beer, wine, and liquor license is:
(1) $15 per day for a religious, fraternal, civic, war veterans', charitable, or hospital supporting organization; and
(2) $25 per day for any other license holder.

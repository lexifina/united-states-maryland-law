# §12-1507
(a) Except as provided in subsection (b) of this section, if an application for a license is denied, the Board may not issue the same class of license to the same applicant or for the same location for 6 months after the denial.
(b) The restriction against the issuance of a license for the same location does not apply if the Board decides that the denial was directed against the applicant and not against the location.

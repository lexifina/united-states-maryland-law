# §11-1306
(a) There is a Class WT wine tasting license.
(b) The Board may issue the license to a holder of a Class BW license or Class BWL license.
(c) The license authorizes the license holder to allow on-premises consumption for tasting of light wine.
(d) The license holder may serve a quantity of not more than 1 ounce from each offering to an individual.
(e) The annual license fee is:
(1) $50 for a holder of a Class BW license; and
(2) $150 for a holder of a Class BWL license.

# §23-1507
(a) If a license application is denied, another license application from the same applicant or for the same location may not be considered for 1 year after the denial.
(b) If a subsequent license application by the same applicant or for the same location is denied within a 2-year period after the first denial, another application may not be considered from that applicant or for that location until the 2-year period expires.

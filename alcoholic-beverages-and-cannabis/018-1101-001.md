# §18-1101.1
(a) There is a Class GC (golf course) privilege.
(b) An owner or operator of a public or private golf course has the privilege of selling alcoholic beverages on the golf course if the owner or operator:
(1) holds a Class B, Class BLX, Class C, Class D, Class H, or Entertainment Facility License; and
(2) pays the annual fee of $200 for the privilege.
(c) The Class GC (golf course) privilege expands the licensed premises to include the golf course.

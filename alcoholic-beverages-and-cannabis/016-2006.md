# §16-2006
This article does not restrict on January 1:
(1) the sale of alcoholic beverages by a holder of a Class B, Class C, Class H, or per diem license from midnight to 3 a.m.; or
(2) a person from consuming alcoholic beverages from midnight to 3 a.m. on the premises of a holder of a Class B, Class C, Class H, or per diem license.

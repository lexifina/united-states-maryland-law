# §12-1311
(a) The Board shall set the license fee for a Class C per diem beer license and a Class C per diem beer and wine license.
(b)
(1) The Board shall set the license fee for a Class C per diem beer, wine, and liquor license.
(2) The Board may collect from the license holder reimbursement for costs incurred while monitoring the event for which the license is issued.
(c) The Board shall impose a fee of not more than $250 for expedited processing of a per diem license application if the application is submitted less than 2 weeks before the scheduled event requiring the per diem license.

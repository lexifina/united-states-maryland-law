# §20-1312
(a) There is a Class C per diem beer and a Class C per diem beer and wine license.
(b) An applicant may purchase:
(1) a Class C per diem beer license or a Class C per diem beer and wine license for each day a license is required; or
(2) a Class C multiday beer license or a Class C multiday beer and wine license for all days for which a license is required.
(c) The days for which licenses under this section may be issued to a single applicant may not exceed 50 in a calendar year.
(d) The fee is $10 per day for:
(1) a Class C per diem beer license;
(2) a Class C per diem beer and wine license;
(3) a Class C multiday beer license; or
(4) a Class C multiday beer and wine license.

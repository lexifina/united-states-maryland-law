# §8
Notwithstanding any other provisions of this Article, the General Assembly has exclusive power to enact, amend, or repeal any local law for a code county which (1) authorizes or places a maximum limit upon the rate of property taxes which may be imposed by the code county; or (2) authorizes or regulates the maximum amount of indebtedness which may be incurred by the code county. Public local laws enacted by the General Assembly under this section prevail over any public local laws enacted by the code county under other sections in this Article.

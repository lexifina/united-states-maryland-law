# §6-107.3
(a) Except as provided in subsection (b) of this section, a person may not use, sell, or distribute for use or sale within the State any commercial feed intended for use as poultry feed that contains:
(1) Roxarsone; or
(2) Any other additive that contains arsenic.
(b) A person may use, sell, or distribute for use or sale within the State any commercial feed intended for use as poultry feed that contains histostat.
